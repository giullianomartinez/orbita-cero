# Orbita Cero

Orbita Cero es un videojuego 2D espacial en el que el jugador controla una nave, combate naves enemigas y avanza por rondas.

En desarrollo.

## Equipo

- Giulliano Martínez
- Ethan Troncoso
- Patricio Hernández

## Tecnologías

- Java
- libGDX
- LWJGL3
- Gradle

## Ejecución

Se requiere tener **Java** instalado.

### Windows

Ejecutar:

```text
JUGAR.bat
```

O desde una terminal:

```bash
gradlew.bat :lwjgl3:run
```

### Linux / macOS

```bash
./gradlew :lwjgl3:run
```
